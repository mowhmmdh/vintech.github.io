Baseline امنیت شبکه برای کسب‌وکارها

یک زیرساخت امن از کنترل‌های قابل‌اندازه‌گیری ساخته می‌شود، نه از فهرست بلند ابزارها. این چارچوب برای شروع ارزیابی امنیت شبکه طراحی شده است.

Asset Inventory → Segmentation → Access Control → Firewall → Logging → Backup → Monitoring → Review

دارایی و مسیرهای دسترسی

سرورها، کلاینت‌ها، تجهیزات شبکه، سرویس‌های ابری و تجهیزات جانبی را فهرست کنید و مسیرهای مدیریتی را مشخص کنید. نقاط ناشناخته معمولاً نقاط کور امنیتی هستند.

Segmentation

شبکه کاربران، سرورها، مهمان، مدیریت و IoT را بر اساس نیاز جدا کنید. Segmentation باید با Policy همراه باشد تا صرفاً جداسازی منطقی روی کاغذ نباشد.

Firewall و Least Privilege

هر Rule باید دلیل، مبدأ، مقصد، سرویس و مالک داشته باشد. Ruleهای بلااستفاده و دسترسی‌های مدیریتی غیرضروری را دوره‌ای بازبینی کنید.

Logging و Monitoring

لاگ‌های مهم را جمع‌آوری کنید و برای رخدادهای معنی‌دار Alert داشته باشید. Availability، Latency، خطاهای Interface و ظرفیت نیز باید در دید عملیاتی باشند.

Backup و Recovery

Backup باید محافظت‌شده و قابل بازیابی باشد. تست Restore و مستندسازی Recovery بخش جدایی‌ناپذیر Baseline است.

جمع‌بندی

هدف Baseline ایجاد یک نقطه شروع قابل‌سنجش است. پس از هر تغییر مهم، وضعیت باید دوباره ارزیابی شود تا امنیت به یک فرآیند مستمر تبدیل شود.
